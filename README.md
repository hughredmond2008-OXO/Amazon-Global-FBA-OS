# Amazon Global FBA OS

This repository is designed as an operating system framework for Amazon global marketplace operations.

It provides an initial folder structure for organizing reusable skills, marketplace knowledge, templates, product information, competitor research, advertising resources, customer feedback, and marketplace data.

## Structure

- `skills/` — Operational skills and workflows for Amazon global marketplace work.
  - `amazon-global-listing-optimizer/` — Framework location for listing optimization skill assets.
- `knowledge-base/` — Reference material organized by operational domain.
  - `marketplaces/`
  - `categories/`
  - `products/`
  - `competitors/`
  - `advertising/`
  - `customer-feedback/`
- `templates/` — Empty template framework for future operational documents.
- `products/` — Product-specific operating files and documentation.
- `competitors/` — Competitor research framework.
- `advertising/` — Advertising operations framework.
- `customer-feedback/` — Customer feedback collection and analysis framework.
- `marketplace-data/` — Marketplace data storage framework.

No sample or fake operational data is included. The repository currently contains only the framework needed to begin building Amazon global marketplace operating processes.
