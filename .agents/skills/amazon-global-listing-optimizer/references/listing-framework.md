# Listing Framework

## Title
Build around product identity, key function/differentiator, important factual specification, compatibility/use case, and pack/count/size when relevant. Follow the current character and formatting requirements supplied by the user.

## Product Highlights / Bullets
Cover clear customer-relevant facts such as function, construction, usability, compatibility, package contents, and differentiation. Avoid unsupported superlatives, guarantees, medical claims, or unverifiable performance claims.

## Product Description
Explain what the product is, its use case, key design/features, how it is used, package contents, and relevant compatibility or limitations.

## Attributes
Use only attributes supported by reliable product facts. Keep terminology consistent with the marketplace and variation theme.

## Backend Keywords
Suggest relevant search terms while avoiding unsupported claims, irrelevant traffic terms, duplicate stuffing, misleading compatibility, and inappropriate competitor-brand terms.

## Variation Strategy
Use a variation theme only when products are legitimate children of the same parent. Choose shopper-intuitive attributes that accurately describe differences.

## Final QA
Check marketplace, factual claims, title/highlight consistency, dimensions/units, compatibility, package quantity, variation names, localization, and keyword relevance.
