# Marketplace Selection

## Required rule
Before creating marketplace-specific listing copy, confirm exactly one target marketplace.

Examples:
- Amazon.com — United States
- Amazon.ca — Canada
- Amazon.com.au — Australia
- Amazon.co.uk — United Kingdom
- Amazon.de — Germany
- Amazon.co.jp — Japan
- Other single Amazon marketplaces when explicitly requested

If none is selected, ask: "Which single Amazon marketplace should I optimize for?"

## Inputs
Collect or infer from provided source material:
- Marketplace and locale
- Product name/category
- Current listing
- Dimensions and weight
- Materials
- Included items
- Compatibility
- Primary use cases
- Differentiators
- Restrictions/exclusions
- Variation structure
- Existing keywords or advertising data
- Character limits or UI requirements

## Locale
Use the marketplace's normal language, spelling, units, terminology, and shopper expectations. Do not treat machine translation as marketplace-native localization.
