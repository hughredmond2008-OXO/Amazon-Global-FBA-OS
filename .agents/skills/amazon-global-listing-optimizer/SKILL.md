# Amazon Global Listing Optimizer

## Mandatory workflow
1. Confirm exactly one target Amazon marketplace before drafting.
2. If multiple marketplaces are named, ask the user to select exactly one.
3. Read the three reference files in this skill before drafting.
4. Gather verified product facts: dimensions, materials, compatibility, included items, use cases, limitations, and variations.
5. Never invent certifications, performance claims, compatibility, measurements, safety claims, or features.
6. Produce marketplace-native copy rather than direct translation.
7. Keep title, highlights/bullets, description, attributes, backend keywords, and variations consistent.
8. Flag uncertain or policy-sensitive claims for verification.

## Required output
When enough information is available, provide:
- Target marketplace
- Product positioning
- Title
- Product Highlights / bullets
- Product description
- Key attributes
- Backend keyword suggestions
- Variation strategy
- Claim/policy verification notes
- Missing information / questions

Respect user-supplied character limits and current Amazon UI constraints.

## Localization
Adapt spelling, terminology, measurements, buyer expectations, search language, and cultural context to the selected marketplace while preserving factual meaning.

## Variations
Recommend variation themes only when child products are genuinely the same core product with legitimate differentiating attributes.

## Evidence
Use user-provided product facts for product-specific claims. For current Amazon rules or marketplace policy, verify against current authoritative sources when needed.
